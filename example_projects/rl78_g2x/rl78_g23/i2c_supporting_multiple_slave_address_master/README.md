# RL78/G23 I2C Supporting Multiple Slave Address (Master)

日本語版は[こちら](./READMEJP.md)

## Overview
This application note describes how to use the master function of the I2C bus by using the IICA serial interface. In the procedure described, you will operate four serial memory areas (256 bytes x 4) specified by different slave addresses. This application note is associated with the application note of "I2C Supporting Multiple Slave Addresses (Slave)".
