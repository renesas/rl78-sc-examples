1. Project Overview:
    This example project demonstrates a basic blinky application on Renesas RL78 MCUs.
    LED1 and LED2 blink periodically. Each time SW1 is pressed, the blink speed toggles (Slow/Fast).

2. Software Requirements:
	CS+ for CC: V8.16.00
	e2 studio: Version 2026-07
	Smart Configurator for RL78: Version 1.18.00
	CC-RL: Version 1.16.00
    
3. Hardware Requirements:
	Supported RL78 Boards: FPB-RL78G23-128p
	1 x Renesas RL78 board.
	1 x Micro-B USB cable.

4. Hardware Connections:
	Connect the USB Debug port on the RL78 board to the host PC via a Micro-B USB cable.
