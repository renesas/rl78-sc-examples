# RL78/G23 Serial Interface UARTA

日本語版は[こちら](./READMEJP.md)

## Overview
This application note explains how to use UART communication through the serial interface UARTA. It demonstrates how ASCII characters received from a counterpart device are analyzed and corresponding responses are transmitted. The sample program includes handling for normal communication as well as error conditions. Interrupt-driven processing is used for reception, transmission, and error handling.
