# RL78/G24 タイマRD2 タイマモード（PWM機能）

English page is [here](./README.md)

## 概要
本アプリケーションノートでは、RL78/G24 のタイマRD2を用いたPWM波形の出力方法について説明します。周期100µsで3種類のデューティ比を持つPWM信号を生成する例を示します。設定方法や出力波形の動作、割り込み処理について解説しています。スマート・コンフィグレータ設定とサンプルコードが提供されています。
