# RL78/G24 Timer RD2 in Timer Mode (PWM Function)

日本語版は[こちら](./READMEJP.md)

## Overview
This application note describes how to output PWM waveforms using the Timer RD2 peripheral in timer mode on the RL78/G24. It demonstrates generating three PWM signals with a 100 µs period and different duty cycles. The document explains configuration settings, waveform behavior, and interrupt handling. Sample code and Smart Configurator settings are provided to support implementation.
