# RL78/G24 A/D Converter (Advanced Mode Enabled)

日本語版は[こちら](./READMEJP.md)

## Overview
This application note explains the functions and operation of the RL78/G24 A/D converter in advanced mode using two practical usage examples. It introduces multi-channel conversion, flexible trigger assignment, and interrupt handling. The document demonstrates both mixed hardware/software trigger operation and simultaneous sampling. Detailed configuration and sample code are provided to support implementation and evaluation.
