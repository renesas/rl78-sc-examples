# RL78/G24 Timer RD2 Using Input Capture Function and Output Compare Function

日本語版は[こちら](./READMEJP.md)

## Overview
This application note explains how to use both the input capture and output compare functions of Timer RD2 on the RL78/G24. The input capture function measures pulse width from an external waveform input. The output compare function controls output timing on specific pins. It demonstrates combining both functions using Smart Configurator with additional user code. Sample configurations and implementation details are provided.
